# Guia de assets — VTS-only

O runtime oficial não possui pack visual interno. Assets e modelos pertencem ao VTube Studio e não são copiados, convertidos ou versionados neste repositório.

A ponte aceita o sender Spout2 do VTS e descobre capabilities do modelo atual pela API local. Trocar o modelo no VTS não exige alteração na NYRA. Configurações locais podem mapear emoção para hotkey/expression existente, sempre com fallback neutro.

Materiais artísticos futuros devem permanecer fora do runtime até haver decisão explícita de produto e validação de licença, alpha e privacidade.
