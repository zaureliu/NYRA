# NYRA 0.4.0 — Intelligence Platform V2

Esta release publica o estado promovido do Mega Upgrade V2 junto das correções atuais do runtime oficial.

## Principais entregas

- `app.intelligence`: Memory V2, RAG local, Context Engine, Model Router V2, Skills, Capability Registry, Tasks, Event Intelligence, Diagnostics, Trace/Replay, Evaluation Suite, trust boundaries, vision adapter e Action Budget.
- Desktop semântico com identidade canônica de aplicativos, deduplicação de discovery, aliases, janela existente primeiro, comandos compostos e verificação por step.
- Browser Operator DOM/CDP-first e visão estrutural integrada ao estado real.
- Operations UI com telemetria Intelligence real e estados `AVAILABLE`, `DEGRADED`, `OFFLINE`, `DISABLED`, `UNCONFIGURED`, `BLOCKED` e `UNKNOWN`.
- SelfDev V2 com reproduce, root-cause analysis, static analysis, regression benchmark, canary e behavior comparison, sem relaxar gates V1.
- Respostas de controle de aplicativos humanizadas; metadata técnica permanece interna e consultável explicitamente.

## Segurança e privacidade

- Documentos, páginas web, memória e resultados de tools são dados sem autoridade de instrução.
- RAG e vision aplicam allowlist e contenção canônica de paths.
- Replays são dry-run por padrão e não repetem ações externas/destrutivas cegamente.
- Configs reais de rede ficam em `config/*.local.*`, ignoradas; apenas templates vazios são publicados.
- Corpus de knowledge, PDFs, bancos, traces, memória, áudio, modelos e artefatos SelfDev não fazem parte da release Git.

## Estado de validação

- Memory V2, RAG, Context, Model Router, Tasks, Capabilities, Diagnostics e Trace/Replay: validados no runtime oficial.
- Browser, Desktop e Operations UI: integrações reais condicionadas ao ambiente, com testes direcionados e effect verification preservada.
- SelfDev V2: lifecycle e rollback validados em repositório isolado; partes de restart/canary permanecem simulation-validated.
- Vision por modelo: opcional; sem modelo Ollama compatível, o estado correto é `UNCONFIGURED`, mantendo visão estrutural.

## Limitações conhecidas

- Integrações Home Assistant, OpenWrt, Proxmox, Sentinel, VTube Studio e Browser dependem de configuração e serviços externos.
- Seis falhas herdadas/ambientais conhecidas permanecem na suíte global: uma Home Assistant, uma fixture TTS, duas USB e duas VoiceHunter. Elas não foram introduzidas pelo Mega Upgrade.
- Modelos, corpus e configurações privados precisam ser provisionados localmente e não acompanham o clone público.
