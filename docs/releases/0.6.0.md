# Kazumi v0.6.0

NYRA is now **Kazumi**. This release changes the product name while preserving
the existing modular, local-first architecture and operator data.

The current interface, assistant identity, default wake word, launchers, backend,
desktop and installer use Kazumi. Natural Conversation, Web Research, Hardware
Engineering, optional cloud voice providers and VTube Studio-only presence remain
part of the same runtime; no replacement engines are introduced.

## Upgrading

Read the [migration guide](../migration/nyra-to-kazumi.md). Stop the old application
before moving data. The migration checks database integrity and row counts,
preserves customized wake words/provider preferences, and retains protected
legacy credentials for rollback. Compatibility aliases remain for one transition
release. The technical Tauri application identifier stays unchanged to preserve
upgrade and WebView preferences.

Older releases keep their historical NYRA names. Repository URLs now use
`zaureliu/Kazumi`; update local Git remotes explicitly.

## Privacy and limitations

Knowledge, generated projects, recordings, credentials, conversation databases,
SelfDev artifacts and third-party VTube models are not included in public source.
Cloud providers require opt-in credentials and may have usage costs. Local
fallbacks depend on installed local models. Physical hardware effects require
actual devices and verification. VTube expressions depend on the loaded rig.

This public release retains source-archive distribution. Windows installers can
be built from the public source; prebuilt installers are not attached while the
redistribution notices for bundled third-party speech binaries are being reviewed.
