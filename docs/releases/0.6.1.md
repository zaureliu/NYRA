# Kazumi v0.6.1

This patch release verifies the public TTS credential-restart fix and aligns
public version metadata to 0.6.1.

## Scope

The canonical commit c48d97a and consolidated public commit 51b7bd2 already contain
identical TTS credential lookup code, restart regression tests and migration
documentation. Different commit IDs reflect different histories, not a missing
fix. Version 0.6.1 does not reapply or replace that implementation.

TTS readiness reads the protected credential vault rather than relying on a
transient metadata index. Existing Gradium and Deepgram credentials do not need
to be entered again. Provider configuration and opt-in cloud policy are unchanged.

The v0.6.0 tag remains untouched. Pending local VTube Studio work, credentials,
runtime databases and other private data are excluded.

## Distribution

Source archives only, as in v0.6.0. Prebuilt installers are not attached while
redistribution notices for bundled third-party speech binaries are reviewed.
See the [migration guide](../migration/nyra-to-kazumi.md) for existing installations.
