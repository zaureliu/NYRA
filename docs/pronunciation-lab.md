# Pronunciation Lab

Em `Settings → Pronunciation Lab`, busque um termo, escolha o provider, edite a `spoken form`, execute o preview e use `Ouvir original`/`Ouvir corrigido`. `Salvar para NYRA` grava o override e a próxima síntese o utiliza sem reiniciar o backend.

O painel mostra display, speech e regras aplicadas. Export/import usa JSON validado. Defaults não são sobrescritos; `Resetar` limpa apenas o campo em edição. O provider online recebe somente o speech text atual.
